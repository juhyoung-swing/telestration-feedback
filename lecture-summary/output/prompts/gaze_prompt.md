# 3. 한 장으로 옮기면

담을 것은 해법 세 문장, 그중에서도 이 하나다.

```
유닛턴을 하면서 상대방을 째려보는 거예요.
```

## 구성

정면에서 본 한 사람. 유닛턴을 마치고 공을 째려보는 순간.

```
몸        옆으로 틀어져 있다 — 어깨가 카메라를 향하지 않는다
얼굴      공 쪽으로 돌아가 있다
시선      머리에서 공까지 이어지는 화살표          ← 노랑
공        시선이 가리키는 끝, 몸에서 떨어진 자리
타점      그 공 자리에 겹치는 원                  ← 노랑
```

**시선 화살표가 공까지 이어지고, 그 끝이 곧 타점이다.**
`시선이 옆이 정면이 되게 되다 보니까 거리를 정확하게 멀리 두게 돼요` 가 이 한 줄로 보인다 —
보는 곳이 치는 곳이고, 몸을 틀었으니 그 자리가 멀다.

## 받았을 때 확인

- 어깨가 카메라를 정면으로 마주보지 **않는가**. 정면이면 유닛턴이 안 그려진 것
- 고개가 공 쪽으로 돌아가 있는가
- 시선 화살표가 **머리에서 시작해 공에서 끝나는가**
- 공이 몸에서 뚜렷이 떨어져 있는가. 몸에 붙어 있으면 이 유닛의 요지가 사라진다
- 노랑이 화살표와 원, 그 둘뿐인가
- 얼굴·글자가 없는가
