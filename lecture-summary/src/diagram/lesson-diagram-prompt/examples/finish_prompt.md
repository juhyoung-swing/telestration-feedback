# 2. 이 유닛의 전체 내용

편집본 `04:38.5 – 05:57.5` · 1분 19초.

### 문제
```
시선 골반에 잘했는데 잘하고도 스윙이 안 나오시는 분들이 꼭 있어요.
```

### 원인
```
그 이유는 마지막 피니시를 겨드랑이와 팔에 붙어서 당기는 스윙을 나올 때,
그럴 때는 뒤에 테이크백을 잘 만들어 놓고도 안 나오는 스윙이 완성이 되기 때문에.
```

### 해법  ★ 이 유닛의 축
```
제가 회원들한테 뭘 시키냐면 — 큰 공이 가슴이랑 팔 사이에 있다고 생각하고
피니시 공간을 크게 만들라고 합니다.
그러면 이 피니시가 자연스럽게 나오면서 선수들이 하는 피니시를 만들 수 있는데.
```

### 어렵다면
```
골반 임팩트 해결하고, 그 다음에 이 오른손 팔꿈치를 왼손바닥으로 밀어주고
그대로 올라가면서 피니시를 만들면 제가 원하는 피니시의 거리가 만들어집니다.
근데 이것도 어렵다. 그러면 농구공 다이소에 다 있을 거예요.
이 농구공 크기만큼만 라켓이 감싸주면 피니시가 예쁜 스윙이 만들어집니다.
```

### 왜
```
이 스윙을 만드는 이유는 이 헤드가 던져지면서 힘을 내야 되는데,
당기는 스윙이 나오면서 힘이 빠지고 오히려 원하는 코스나 공에
힘을 주지 못하기 때문에. 얘를 던져주려고 피니시를 크게 잡는다고 보시면 돼요.
```

### 정리
```
이 유닛에는 3단계 자막이 없다. 시선은 02:23.5, 골반은 04:02.5 에 세 개씩 박혀 있는데
여기만 비어 있다. 수업 후 체크리스트의 피니시 행이 그래서 미완성이다 — 코치 확인 필요.
```

04:58.5  그래픽  삽입 오브젝트(농구공) → 가슴과 팔 사이 공간 시각화

# 3. 한 장으로 옮기면

담을 것은 이 하나다.

```
큰 공이 가슴이랑 팔 사이에 있다고 생각하고 피니시 공간을 크게 만들라고 합니다.
```

## 구성

정면에서 본 한 사람. 라켓이 피니시 자리에 와 있고, 가슴과 팔 사이가 벌어져 있다.

```
자세    피니시 — 오른팔이 몸을 가로질러 올라가 있다
공간    가슴과 위팔 사이가 뚜렷이 벌어져 있다
표시    그 공간에 딱 맞는 원                    ← 노랑
```

**공을 그리지 않는다.** 참조 사진에는 농구공이 들어 있지만, 그건 확인 도구지 목표가 아니다.
그 자리를 노란 원으로 바꾸면 `공 없이도 이 자리를 유지하라` 가 된다.

앞의 두 도해와 같은 문법이다.

```
시선   노란 화살표가 시선의 길       — 보이지 않는 것을 그린다
골반   노란 실선/점선이 회전의 순서   — 보이지 않는 것을 그린다
피니시  노란 원이 비어 있어야 할 자리  — 보이지 않는 것을 그린다
```

## 받았을 때 확인

- **가슴과 위팔 사이가 벌어져 있는가.** 붙어 있으면 이 도해의 뜻이 사라진다
- 노란 원이 그 벌어진 자리에 **끼어** 있는가. 가슴 한복판에 얹혀 있으면 실패
- 원이 농구공처럼 보이지 않는가 — 이음선·질감이 있으면 소품으로 읽힌다
- 라켓이 머리 옆 높은 곳에 있는가
- 노랑이 원 하나뿐인가 · 얼굴·글자가 없는가
