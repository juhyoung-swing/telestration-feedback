## 코치 확인란

AI가 뽑은 후보이므로 코치 판단이 필요한 항목입니다.

- [ ] 좋은 장면 3개가 실제로 칭찬할 순간인가
- [ ] 개선점 순서(손목 → 라켓면 → 허리)가 맞는가
- [ ] 숙제가 이 학습자 수준에 적절한가
- [ ] 학습자에게 보낼 클립 4개 선택 (기본: fb2, fb3, fb4, fb5)

### 분류 방법의 한계

지적 횟수는 **키워드 카운트가 아니라 발화 맥락 분류**입니다. `손목`이라는 단어는 전사 전체에 17회 나오지만, 그중 다수는 카메라를 향한 개념 설명입니다:

```
[08:15] 돌리다 보면은 손목을            ← 설명 (초보자 일반론)
[08:48] 손목을 안 쓸려고 지금 덮으라고    ← 설명
[06:49] 하나 여기 이제 손목 너무 강하게    ← 이 학습자에게 직접 지적
```

구분 기준은 어미와 인칭입니다 — `~하시는 분들이 많아요`(설명) vs `지금~`, `~주시고`(지적). **경계가 애매한 발화가 있으므로 코치 확인이 필요합니다.** 실제 수업에서는 카메라 향한 설명이 없어 이 구분 문제가 크게 줄어듭니다.
