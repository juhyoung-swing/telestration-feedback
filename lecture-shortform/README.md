# 교육 숏폼

레슨 영상에서 **티칭 포인트가 되는 구간**을 골라 세로 클립으로 뽑는다.
Reels · Shorts · TikTok 규격.

## 숏폼은 하나가 아니다

포맷은 같고 **판단이 다르다.** 판단이 다르면 기능이 다르다.

```
같은 것   9:16 리프레임 · 자막 · 20~25초 · 인코딩        실행
다른 것   어느 구간을 고를 것인가                       판단
```

| | 무엇을 고르나 | 입력 | 상태 |
|---|---|---|---|
| **교육 숏폼** (여기) | 티칭 포인트 | 레슨 영상 + 전사 | 데모 |
| 마케팅 숏폼 | 훅이 되는 구간 | 레슨 영상 + 전사 | 없음 |
| 하이라이트 숏폼 | 잘한 랠리 | **랠리 JSON** — 대본 없음 | 없음 · `rally-*` 쪽 |

하이라이트는 입력 자체가 다르다. `../rally-detect` 결과를 먹으므로 `rally-highlight`
로 나가야 한다. 여기 코드를 재사용할 수 있는 건 **리프레임·인코딩뿐**이다.

> 리프레임을 공용 폴더로 빼지 않았다. 아직 코드가 없어서(중앙 고정 크롭)
> 지금 빼면 빈 껍데기가 생긴다. **두 번째 사용자가 생길 때 뺀다.**

## `../video-edit` 와 다른 점

| | video-edit | 여기 |
|---|---|---|
| 입력 | 강의 원본 + **대본** | 레슨 원본, **대본 없음** |
| 판단 기준 | 대본과 일치하는가 | **좋은 구간인가** |
| 출력 | 완성 강의 1개 (가로) | 세로 클립 여러 개 |
| 무음 | 무음 ≠ 삭제 (시범 보호) | 무음이 거의 없음 (계속 말함) |

**판단이 "일치" 가 아니라 "선별" 이라 코드를 공유하지 않는다.**

## 데모만이라고 하는 이유

**`.py` 파일이 0개다.** 전부 명령을 손으로 돌려서 만들었다.
옮길 코드가 없고 산출물과 편집 지시서만 있다.

## 두 가지가 특이하다

**CapCut 자동자막을 썼다.** 데스크톱 프로젝트의 `draft_info.json` 이 평문이라
439줄 자막을 읽어 `transcript_raw.srt` 로 뽑았다. `output/draft_backup_0812/` 참고.

**테니스 용어 오인식을 손으로 교정했다.**

```
락캠 / 락캠면        → 라켓 / 라켓면
세미에스턴 / 위스턴   → 세미웨스턴 / 웨스턴
압수하듯이          → 악수하듯이
수행 / 수행하세요    → 스윙 / 스윙하세요
탓점               → 타점
```

**전사 후처리에 테니스 용어 사전이 필요하다는 증거다.** 다른 기능에도 해당한다.

현재   1080×1920 · 중앙 고정 크롭 (x=656)
