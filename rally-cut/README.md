# 경기 영상 편집

포인트 사이 빈 시간을 걷어내 액션만 남긴 영상을 만든다.
긴 경기 하나가 랠리만 이어진 영상이 된다.

## 나온 것

```
match_f.mp4  15분(900초)
  → 랠리 36개 · 합 386초
  → output/match_f_rallies.mp4  460초
```

랠리 길이 중앙값 9.8초 · 최소 3.1초 · 최대 33.6초

## 반쯤이라고 하는 이유

```
1  자르는 스크립트가 없다
   기존 하이라이트는 ffmpeg 을 손으로 돌려 만들었다. 30줄이면 되는데 없다.

2  입력이 되는 랠리 검출이 미검증이다
   ../rally-detect 참고. 랠리 끝을 검출하지 않아 데드타임이 섞여 있다.
```

압축률 43%로 나왔는데 프로 경기 실측(보통 20~30%)보다 높다. **데드타임이 상당히
랠리 안에 들어간 것으로 보인다.**

## 구조

```
랠리 JSON  →  ffmpeg concat (앞뒤 패딩)  →  하이라이트 영상
```

판단은 `../rally-detect` 가 하고, 여기는 자르기만 한다.
**랠리 검출이 새로 나오면 이 폴더는 거의 안 바뀐다.**

## 할 일

1. `rallies_<tag>.json → mp4` 스크립트 하나 (앞뒤 1초 패딩)
2. `../rally-detect` 결과로 교체
3. 정답 라벨로 압축률·끊김 수 재측정 — `output/labeling.html`

## output

```
rallies_match_{b,d,e,f}.json    기존 검출 결과
match_f_rallies.mp4             수동으로 만든 하이라이트
labeling.html                   정답 라벨링 도구 (아직 안 쓴 것)
```
