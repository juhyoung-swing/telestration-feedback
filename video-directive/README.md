# 편집 지시서

전사와 대본을 맞춰 **무엇을 어떻게 자를지 확정한다.**
출력이 둘이다 — 기계가 먹는 지시서, 사람 편집자가 읽는 대본.

```
directive.json    → ../video-edit 가 기계적으로 실행한다
script.html       → 사람 편집자가 읽는다
```

**"영상을 대본화해서 편집자에게 맡기면 되냐"** 는 질문의 답이 두 번째다.
자동 편집을 안 쓰더라도 이 산출물만으로 외주 편집이 돌아간다.

## 여기가 유일하게 판단하는 곳이다

```
../video-transcribe   관찰   사실만. 목적과 무관.
여기                  판단   목적이 들어간다.
../video-edit         실행   지시서를 기계적으로. 새 판단을 하지 않는다.
```

**같은 영상이 강의도 되고 마케팅 릴도 되는 건 여기서 갈린다.**
결과에 문제가 있으면 지시서만 보면 원인을 추적할 수 있다.

## 판단 규칙 R1~R7

사람 편집본과 대조해서 얻었다. 우리 컷은 뭉텅이 5개였는데 사람은 35개를 잘랐고,
그 중 44초를 놓쳤다(`human_diff.json`). 놓친 것들은 전부 말 사이 잔가지였다.
**그 잔가지에 이름을 붙인 것이 규칙이다.**

| | 규칙 | 목적 의존 |
|---|---|---|
| R1 | 다시 말하기 — 같은 말로 다음 문장이 시작하면 앞엣것을 버린다 | 중립 |
| R2 | 자문자답 도입 — `~냐면` 으로 끝나는 짧은 문장은 버린다 | 중립 |
| R3 | **챕터 카드가 이미 말한 도입은 버린다** | 강의 구조를 전제 |
| R4 | 문장 머리의 연결어·군더더기는 문장을 살린 채 앞만 떼어낸다 | 중립 |
| R5 | **내용어(용어집)가 들어 있으면 문장을 통째로 버리지 않는다** | 도메인 사전에 의존 |
| R6 | `no_speech_prob > 0.5` 는 무발화 구간의 환각이므로 버린다 | 중립 |
| R7 | 살아남은 구간 사이가 N초 미만이면 붙여서 한 컷으로 둔다 | 중립 |

**판단은 문장마다 사유와 함께 남긴다** — 왜 잘렸는지 사람이 확인할 수 있어야 한다.
`output/trim_decisions.json`

## 지금의 구조적 문제

**R1~R7이 `trim_script.py` 안에 하드코딩돼 있다.**
`prompts/` 폴더를 만들어놓고 비워 뒀다(`.gitkeep` 만 있었다).

```
지금    규칙이 코드에 박혀 있어 목적을 갈아끼울 수 없다
        → 같은 영상으로 마케팅 지시서를 만들 수 없다

가야 할 곳
        rules/lecture.json     R3 챕터카드 · R5 용어집 · JOIN_GAP
        rules/marketing.json   (예정)
        glossary/              도메인 사전 — 테니스 용어
```

**7개 중 5개가 이미 목적 중립이다.** 뺄 것은 R3·R5와 임계값 몇 개뿐이라
큰 작업이 아니다. 아직 안 했다.

## src

```
s2_storyline_and_directive/
  script.py           대본 매칭
  trim_script.py      ★ R1~R7 판단. 여기가 핵심이고 여기가 하드코딩돼 있다
  rebase_anchors.py   오버레이 앵커를 원본 타임코드로
  script_doc.py       사람이 읽는 대본 문서
  edited_script.py    편집본 대본 (자막·그래픽·SFX 시각까지)
  eval_cuts.py        사람 편집본과 일치율 평가
  diff_human.py       무엇을 놓쳤나
  make_oracle.py      정답지 만들기
  merge_reference.py  참조 병합
  review_html.py      3단 비교 검수 HTML
```

**LLM은 영상을 보지 않는다.** 텍스트(전사·대본)만 읽고 타임코드를 출력한다.

## output

```
directive_{A,B,D,E,H}.json   버전별 지시서. E 가 R1~R7 적용본
trim_decisions.json          문장별 keep/drop 과 사유
human_diff.json              사람 편집본과의 차이
eval_cuts.json               일치율 평가
script.md / .html            지시서 대본
edited_script.md / .html      편집본 대본 — 자막·줌·그래픽이 몇 초에 들어갔는지
schema.md                    지시서 스키마
```

`edited_script.md` 가 특히 쓸모 있다. `lecture-summary` 의 도해와 유닛 경계가
전부 이 문서를 근거로 만들어졌다.
