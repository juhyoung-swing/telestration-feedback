# ACE 사업 로드맵

## Phase 1 — MVP: Content + Coaching + AI

**~2026년 10월**

우선 계획대로 MVP 를 만든다. 김기준 대표의 핵심 커리큘럼과 온라인 강의를 제작하고,
앱에서는 강의 수강뿐 아니라 다음 초기 AI 기능까지 구현한다.

```
레슨 영상 AI 자동편집
주요 장면 추출
Score · Rally · Shot Count
속도
```

초기 목표는 기능을 많이 만드는 것이 아니라, **"좋은 커리큘럼 + 온라인 강의 +
온라인 피드백 + 오프라인 레슨 + AI" 가 결합된 새로운 테니스 학습 경험을 검증**하는 것이다.

## Phase 2 — 1억원 매출 검증 → 투자유치

**~2026년 12월**

첫 번째 중요한 Milestone 은 **온라인 강의 누적 매출 1억원**이다.
1억원 이상 판매되면 콘텐츠에 대한 Product-Market Fit 이 어느 정도 검증됐다고 보고
본격적인 외부 투자유치를 추진한다.

```
Pre-money 기업가치   40억원
목표 투자유치        약 10억원
```

## Phase 3 — 투자받아서 Full ACE 구축

**2027년 1~3월**

투자 이후에는 MVP 수준을 넘어 전체 커리큘럼과 처음 기획했던 ACE 의 앱 기능을
본격적으로 구현한다. 테니스를 배우고 플레이하는 전 과정을 하나의 앱 안에 구축한다.

```
초급~상급 전체 커리큘럼
AI 영상분석 및 코칭
코치/회원 매칭
예약 · 결제
레이팅
경기기록
커뮤니티
```

## Phase 4 — 세 가지 Scale-up Path

**2027년**

이후 ACE 가 크게 성장하는 길은 세 가지가 있다. **지금 하나를 선택하지 않는다.**
MVP 와 초기 매출을 통해 어느 방향의 가능성이 가장 큰지 확인하면서 선택하거나 병행한다.

### ① ACE Academy Network — 하나의 훌륭한 커리큘럼을 전국으로

ACE 커리큘럼 자체가 압도적으로 좋다면 좋은 오프라인 코치와 아카데미를 계속 모집한다.
코치들은 같은 ACE 커리큘럼과 시스템을 활용하고, 고객은 온라인에서 ACE 강의를 듣다가
가까운 ACE Partner Coach 에게 오프라인 레슨을 받는다.

**온라인 ACE → 오프라인 ACE Partner Network.** 전국 어디서나 일관된 수준의 테니스 교육.

### ② ACE Marketplace — 모든 좋은 코치가 들어오는 플랫폼

반대로 다양한 코치와 커리큘럼에 대한 수요가 크다면 ACE 를 개방형 플랫폼으로 발전시킨다.
좋은 코치라면 누구든 자신의 커리큘럼을 만들고 온라인 강의를 판매하며
오프라인 레슨까지 예약받을 수 있게 한다.

```
온라인 강의 매출        20 ~ 40%
오프라인 레슨 수수료     10 ~ 20%   매칭 · 예약 · 결제
```

목표는 양면 플랫폼이다 — **"테니스 코치는 ACE 에서 가르치고, 테니스 고객은 ACE 에서
배우고 코치를 찾는다."**

### ③ ACE Global — 한국 테니스 교육을 해외로

한국의 테니스 티칭은 세계적으로 보더라도 상당히 꼼꼼하고 수준이 높지만,
이를 체계적인 콘텐츠와 상품으로 만들어 해외에 판매하는 사례가 많지 않다.

ACE 가 좋은 커리큘럼을 체계화하고 **AI 번역 · 더빙 · 자막**을 활용해 **일본을 시작으로**
해외에 출시한다. 한국에서 검증된 커리큘럼 + 영상 콘텐츠 + AI Coaching + ACE App
자체를 하나의 교육 상품으로 수출하는 모델이다.

## Long-term Vision

이 세 가지 길은 서로 배타적이지 않다. 다음 순서로 연결될 수도 있다.

```
좋은 ACE 커리큘럼을 만든다
  → 좋은 코치들이 모인다
    → 온라인과 오프라인 네트워크가 커진다
      → 다른 코치들도 자신의 콘텐츠를 올리는 플랫폼이 된다
        → 한국에서 검증된 시스템을 해외로 확장한다
```

궁극적으로 ACE 의 목표는 온라인 강의 회사가 아니라
**Content + Coach Network + Marketplace + AI + Global Distribution** 을 가진
테니스 플랫폼이 되는 것이다.

그리고 **테니스에서 이 모델을 증명하면 같은 구조를 다른 스포츠로 확장한다.**
