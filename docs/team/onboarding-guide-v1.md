**PROJECT ACE**

**팀 온보딩 가이드**

**테니스에서 시작하는 Sports Education Platform**

> **우리가 만드는 것**
> 온라인 스포츠 강의 → 오프라인 레슨 예약·결제 → 실제 수업 → 촬영·코치 피드백 → 다시 연습·플레이까지 하나의 앱에서 연결하는 스포츠 교육 플랫폼을 만든다. 테니스가 첫 번째 종목이지만, 제품의 종착점은 테니스 앱이 아니라 여러 스포츠에서 반복 가능한 교육·운영 플랫폼이다.

**1. 왜 이 프로젝트를 하는가**

**좋은 스포츠 교육은 여전히 “좋은 코치를 우연히 만나는 것”에 많이 의존한다. 온라인 강의는 설명을 제공하지만 실제 레슨과 연결되지 않고, 예약·결제 앱은 운영은 돕지만 학습내용을 남기지 못한다. 촬영·분석 앱 역시 수업과 코치 피드백의 맥락이 분리되어 있다.**

**Project ACE는 이 조각난 경험을 하나의 학습 루프로 연결하려는 프로젝트다.**

| **① 온라인 학습** 개념·전략·드릴 | **② 예약·결제** 코치·시간·장소 | **③ 오프라인 수업** 커리큘럼 기반 | **④ 촬영·피드백** 사람 중심 코칭 | **⑤ 플레이·매칭** 실전 적용 |
|---|---|---|---|---|

**2. 테니스가 시작점인 이유**

- 코칭 품질 편차와 비표준화된 레슨 경험이 크고, 체계적인 커리큘럼에 대한 수요가 명확하다.
- 강의·레슨·경기·영상·매칭이 모두 존재해 전체 학습 루프를 검증하기 좋은 종목이다.
- 성공하면 골프·배드민턴·축구 등 “코칭 + 예약 + 반복학습” 구조가 있는 스포츠로 확장할 수 있다.
> **이번 온보딩에서 기억할 한 문장**
> 우리는 “테니스 콘텐츠 회사”나 “학원 예약 앱” 하나를 만드는 것이 아니다. 스포츠를 배우고, 예약하고, 수업받고, 피드백 받고, 다시 플레이하는 전 과정을 하나의 제품 경험으로 만든다.

**3. 제품을 어떻게 이해하면 되는가**

**제품의 핵심은 기능 수가 아니라 연결성이다. 각각의 기능은 독립 메뉴가 아니라 한 사용자의 학습 여정을 이어주는 역할을 해야 한다.**

| **영역** | **사용자에게 주는 가치** | **핵심 기능** |
|---|---|---|
| 온라인 아카데미 | 수업 전에 이해하고, 수업 후 다시 복습한다. | 강의·드릴·전략·수업 전/후 자료 |
| 오프라인 수업 | 좋은 콘텐츠를 실제 코칭 경험으로 연결한다. | 코치·장소·일정 선택, 예약, 결제 |
| 촬영·피드백 | “무엇이 달라졌는지”를 실제 장면으로 남긴다. | 수업 촬영, 하이라이트, 코치 코멘트 |
| 매칭·플레이 | 배운 내용을 실제 경기에서 반복한다. | 게임/랠리 모집, 수준 프로필, 채팅·평가 |
| Academy/Coach Tools | 좋은 코칭을 코치 개인의 감각에서 시스템으로 바꾼다. | 일정, 회원, 커리큘럼, 피드백, 운영 |

**4. 첫 번째 검증 상품: Game Lesson Package**

**초기에는 모든 테니스 커리큘럼을 만들지 않는다. 하나의 명확한 상품을 끝까지 완성해 “온라인 → 오프라인 → 피드백” 루프가 실제 고객에게 가치가 있는지를 먼저 검증한다.**

| **대상** | 게임 실력을 높이고 싶은 테니스 학습자 |
|---|---|
| 상품 구성 | 온라인 강의 + 오프라인 게임레슨 + 수업 전·후 자료 + 촬영 피드백 |
| 예약/결제 | 앱에서 일정·코치를 확인하고 수업을 예약·결제 |
| 수업 결과물 | 수업 영상, 핵심 장면, 코치 피드백, 다음 연습 포인트 |

**5. 지금 만들지 않는 것**

**장기 제품 범위에는 있지만, 초기 팀이 한 번에 해결하려 하지 않는 영역이다.**

- Shop / 커머스, 대회 운영 기능
- SwingVision 수준의 고급 자동 샷 분석·자동 스코어링
- 대규모 다학원 SaaS 고도화, 일본 현지화, 다종목 확장
- 복잡한 Certification 체계와 코치 네트워크 확장

**단, 현재 구조를 설계할 때 미래 확장을 막는 방식으로 만들지는 않는다.**

**6. 팀이 함께 만드는 세 가지 Workstream**

**소프트웨어만 만들어서는 이 프로젝트가 성립하지 않는다. 교육 IP, 콘텐츠 제작, 제품 개발이 동시에 맞물려야 한다.**

**A. 교육 IP · 커리큘럼 개발**

**목표: 김기준 대표가 가진 현장 노하우를 “누구나 이해하고 반복해서 사용할 수 있는 구조”로 바꾼다.**

| **Step** | **작업** | **산출물/의미** |
|---|---|---|
| 1 | 김기준 대표 초안 | 수업 주제, 드릴, 팁, 경기 상황을 자유롭게 풀어낸다. |
| 2 | 질문 + 해외사례 리서치 | 왜/언제/누구에게 필요한지 질문하고 해외 아카데미의 구조와 비교한다. |
| 3 | 구조화 | 학습목표 → 진단 → 드릴 → 실전 적용 → 성공기준 → 오류/교정으로 정리한다. |
| 4 | 코치 피드백 | 현장성과 테니스 정확성을 김기준 대표가 검수한다. |
| 5 | 최종화 | 학습자용 설명, 코치용 운영안, 촬영용 대본까지 하나의 세션 팩으로 완성한다. |
| 6 | 반복 | Game Lesson Package의 각 세션마다 동일 프로세스를 반복한다. |

**B. 콘텐츠 제작 · 수업자료**

**목표: 확정된 커리큘럼을 학습자가 “보기 좋고 이해하기 쉬운 콘텐츠”로 만들고, 실제 코치가 현장에서 그대로 사용할 수 있게 한다.**

- 김기준 대표 + Sub Coach: 커리큘럼에 맞춘 시범/레슨 촬영, 좋은 예·나쁜 예·대표 상황 구현
- PD: 촬영 기획, 컷 구성, 편집, 자막·그래픽, 온라인 강의용/수업용 버전 제작
- 수업 전 자료: 오늘의 목표, 핵심 개념, 예상 드릴, 경기 상황을 RNA 수준의 상세도로 제공
- 수업 후 자료: 오늘 배운 내용, 핵심 장면, 코치 피드백, 복습영상, 다음 연습 포인트

**C. 소프트웨어 · 서비스 개발**

**목표: 교육 IP와 콘텐츠가 고객의 실제 행동으로 연결되도록 제품 흐름을 구현한다.**

- 학습자: 온라인 강의 → 오프라인 수업 검색/예약/결제 → 수업 전 자료 → 수업 후 영상/피드백
- 코치: 일정 확인 → 수업 내용 확인 → 촬영/업로드 → 핵심 구간 선택 → 구조화 피드백
- 관리자: 수업·코치·콘텐츠·예약·결제의 최소 운영 기능
- 이후 연결: 매칭, 실력 프로필, 코트, 대회, Shop, AI 분석

**7. 온보딩 이후 첫 4주: 무엇을 끝낼 것인가**

**첫 달의 성공은 기능을 많이 만드는 것이 아니라, 하나의 상품을 실제 사용자에게 처음부터 끝까지 제공할 수 있는 상태를 만드는 것이다.**

| **주차** | **교육 IP** | **콘텐츠** | **제품/운영** |
|---|---|---|---|
| Week 1 | Game Lesson Package 구조·세션 수 확정, 첫 세션 초안 | 촬영 포맷·톤앤매너·샘플 구성 확정 | 핵심 사용자 플로우·화면·데이터 구조 확정 |
| Week 2 | 세션별 드릴/코칭포인트 1차 완성 | 첫 강의/드릴 촬영 및 수업 전 자료 제작 | 온라인 강의 + 예약/결제 핵심 플로우 구현 |
| Week 3 | 현장 테스트 후 커리큘럼 수정 | 수업 후 자료·클립·피드백 포맷 확정 | 촬영/업로드 + 코치 피드백 + 결과화면 구현 |
| Week 4 | Game Lesson Package v1 잠금 | 필수 콘텐츠 패키지 완성 | 실제 수업 E2E 테스트, 버그 수정, 첫 고객 운영 준비 |

**8. 팀의 공통 의사결정 원칙**

**• 학습 루프가 우선 — **기능 하나가 멋진가보다 온라인→오프라인→피드백이 끊김 없이 이어지는지가 더 중요하다.

**• 사람이 코칭한다 — **AI는 정리·검색·편집·추천을 돕지만, 핵심 판단과 처방은 코치가 한다.

**• 코치의 머릿속을 자산화한다 — **좋은 코치의 노하우를 영상만 찍는 것이 아니라 구조화된 교육 IP로 남긴다.

**• 처음부터 플랫폼으로 설계한다 — **테니스 MVP를 만들지만 데이터와 구조는 다른 스포츠와 여러 아카데미로 확장 가능해야 한다.

**• 완벽보다 실제 운영 — **문서와 화면보다 실제 수업에서 돌아가는 경험을 빠르게 만들고 반복해서 고친다.

**9. 첫 달이 끝났을 때 팀이 답해야 할 질문**

- 고객은 온라인 자료를 실제로 보고 오프라인 수업에 들어오는가?
- 예약과 결제가 수업 구매를 더 간단하게 만드는가?
- 수업 후 영상과 코치 피드백을 고객이 다시 보는가?
- 코치는 추가 업무 부담 없이 5분 안팎으로 좋은 피드백을 남길 수 있는가?
- Game Lesson Package가 기존 일반 레슨보다 “체계적이고 결과가 남는다”는 인상을 주는가?
> **North Star**
> “수업이 끝나도 학습이 끝나지 않는 스포츠 교육 경험.” 이것이 첫 버전부터 지켜야 할 제품의 중심이다.
