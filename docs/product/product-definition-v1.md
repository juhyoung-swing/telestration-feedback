# Sports Education OS

## 통합 제품 정의서 v0.1

## 1. 프로젝트 개요

### 1.1 프로젝트의 목적

본 프로젝트는 스포츠 학원과 코치가 체계적인 교육 프로그램을 운영하고, 학습자가 온라인과 오프라인을 연결하여 지속적으로 실력을 향상할 수 있도록 하는 통합 스포츠 교육 플랫폼을 구축하는 것을 목적으로 한다.

첫 번째 종목은 테니스로 시작한다.

향후에는 다음 종목으로 확장할 수 있도록 공통 플랫폼과 종목별 교육 모듈을 분리하여 설계한다.

- 골프
- 축구
- 야구
- 농구
- 배드민턴
- 탁구
- 수영
- 피트니스 및 기타 코칭 스포츠

## 2. 제품 비전

스포츠 수업의 예약과 결제를 디지털화하는 것을 넘어,
코치의 교육방법과 학습자의 성장과정을 데이터로 연결하는
아시아 최고의 Sports Education OS를 만든다.

기존 스포츠 학원 솔루션은 주로 예약, 결제, 출결에 머무른다.

기존 스포츠 분석 앱은 영상이나 통계를 제공하지만 실제 코치의 교육과 연결되지 않는다.

기존 온라인 강의 서비스는 콘텐츠를 제공하지만 오프라인 수업과 학습자의 실제 수행 결과를 연결하지 못한다.

본 서비스는 다음의 학습 순환을 하나의 플랫폼에서 구현한다.

### Learning Loop

1. 온라인에서 개념과 드릴을 학습한다.
2. 관련 오프라인 수업을 예약한다.
3. 수업 전 오늘의 목표와 내용을 확인한다.
4. 수업을 촬영하고 자동으로 정리한다.
5. 코치가 영상과 데이터를 바탕으로 피드백한다.
6. 학습자는 복습 영상과 과제를 확인한다.
7. 연습 또는 게임에서 배운 내용을 실행한다.
8. 경기 영상과 평가가 다시 다음 수업에 반영된다.

# 3. 제품 구성

플랫폼은 크게 세 개의 제품으로 구성한다.

## Product A. Academy Admin

학원 운영자와 코치를 위한 웹 및 모바일 앱

## Product B. Player App

수강생과 일반 스포츠 참여자를 위한 모바일 앱

## Product C. Sports Intelligence Platform

영상 처리, 커리큘럼, 평가, 데이터 및 매칭을 담당하는 공통 백엔드

# 8. 영상 촬영 및 분석

## 8.1 기본 방향

영상 기능의 목적은 AI 코치를 만드는 것이 아니다.

목적은 다음과 같다.

- 코치가 짧은 시간에 영상을 검토하도록 지원
- 수업을 자동으로 정리
- 학습자가 자신의 변화를 시각적으로 확인
- 좋은 장면과 문제 장면을 쉽게 공유
- 실제 영상에 근거한 사람 중심의 코칭 제공

## 8.2 촬영 방식

### 방식 1. 학원 고정 카메라

- 코트 또는 연습장에 고정 설치
- 수업 예약과 자동 연결
- 수업 시작 시 자동 또는 코치가 촬영
- 종료 후 회원별 영상 분리

### 방식 2. 코치 스마트폰 또는 태블릿

- 삼각대 설치
- 코치 앱에서 수업 선택 후 촬영
- 촬영 영상이 해당 수업에 자동 연결

### 방식 3. 학습자 스마트폰

- 개인 연습 또는 경기 촬영
- 앱에서 직접 촬영
- 기존 영상 업로드
- 특정 온라인 강의의 과제로 제출

## 9.1 평가의 원칙

실력은 하나의 숫자로만 평가하지 않는다.

### A. Match Level

실제 경기 상대를 정하기 위한 수준

### B. Skill Profile

기술 및 전술별 수준

### C. Learning Progress

교육과정의 진도와 숙련도

## 9.2 테니스 Skill Profile 예시

## 9.3 평가 주체

- 자기평가
- 코치 평가
- 경기 상대 평가
- 경기 결과
- 영상 및 통계
- 공식 레벨 테스트

각 평가의 신뢰도를 다르게 적용한다.

예시:

- 인증 코치 평가: 높은 가중치
- 실제 경기 결과: 높은 가중치
- 영상 통계: 중간 가중치
- 상대방 평가: 중간 또는 낮은 가중치
- 자기평가: 초기 참고값

## 9.4 Verified Level

코치가 직접 부여한 수준에는 인증 표시를 제공한다.

예시:

- Self-Rated 3.0
- Community Rating 3.2
- Coach Verified 3.1
- Match Confidence: High

프로필에는 숫자만 보여주는 것이 아니라 다음도 표시한다.

- 최근 하이라이트
- 경기 횟수
- 최근 전적
- 플레이 스타일
- 선호 게임 형식
- 코치 평가일
- 평가한 코치
- 평가 신뢰도

# 12. 제품 간 핵심 연결 시나리오

## Scenario 1. 온라인에서 오프라인으로

1. 학습자가 백핸드 강의를 본다.
2. 강의 하단의 ’직접 배우기’를 선택한다.
3. 가까운 학원과 해당 커리큘럼을 가르치는 코치가 표시된다.
4. 날짜와 수강권을 선택하여 예약한다.
5. 코치는 학생의 강의 시청 여부와 자가진단을 확인한다.
6. 수업 후 영상과 피드백이 동일 강의 페이지에 연결된다.

## Scenario 2. 오프라인에서 온라인으로

1. 코치가 수업 중 높은 포핸드 처리 문제를 발견한다.
2. 해당 평가항목을 선택한다.
3. 관련 온라인 강의와 드릴이 자동 추천된다.
4. 코치는 적절한 자료를 학생에게 과제로 지정한다.
5. 학생은 강의를 본 뒤 연습 영상을 제출한다.
6. 코치는 영상을 리뷰하고 다음 수업을 추천한다.

## Scenario 3. 경기에서 레슨으로

1. 학습자가 매칭을 통해 경기를 한다.
2. 경기를 앱으로 촬영한다.
3. 영상에서 짧은 랠리, 실책, 서브 등의 클립이 생성된다.
4. 학습자가 코치 리뷰를 신청한다.
5. 코치는 반복되는 문제를 진단한다.
6. 관련 강의와 오프라인 클리닉을 추천한다.

## Scenario 4. 레슨에서 매칭으로

1. 코치가 학생의 수준을 인증한다.
2. 학생 프로필에 Coach Verified Level이 표시된다.
3. 비슷한 실력의 연습상대와 게임을 추천한다.
4. 코치는 특정 경기과제를 지정한다.
5. 경기 결과가 다음 수업자료로 연결된다.

# 17. 제품의 핵심 차별점

## 1. 예약 앱이 아니라 교육 플랫폼

수업을 예약하는 것에 그치지 않고 무엇을 배우고 어떻게 성장했는지를 관리한다.

## 2. 콘텐츠와 현장을 연결

온라인 강의에서 바로 오프라인 수업을 예약하고, 오프라인 수업 결과가 다시 온라인 학습으로 이어진다.

## 3. AI가 아닌 Human-in-the-Loop Coaching

AI는 영상을 찾고 자르고 분류하고 정리한다.

최종 진단과 처방은 코치가 한다.

## 4. 검증 가능한 실력 프로필

자기신고 레벨뿐 아니라 코치 평가, 실제 경기, 영상과 통계에 근거한 프로필을 제공한다.

## 5. 코치의 노하우를 자산화

좋은 코치의 지식이 개인의 머릿속에 머무르지 않고 커리큘럼, 드릴, 콘텐츠와 평가체계로 축적된다.

## 6. 다종목 확장 가능

테니스에 최적화해 시작하지만 플랫폼의 핵심 데이터와 운영기능은 다른 코칭 스포츠에서도 재사용한다.

# 18. 첫 번째 제품 원칙

1. 모든 수업에는 명확한 학습목표가 있어야 한다.
2. 모든 수업은 커리큘럼 또는 드릴과 연결되어야 한다.
3. 모든 피드백은 실제 장면이나 평가항목에 근거해야 한다.
4. AI가 코치의 최종 판단을 대신하지 않는다.
5. 학습자의 영상과 평가 이력은 하나의 Journey에 축적된다.
6. 학원은 자체 커리큘럼과 공통 커리큘럼을 함께 사용할 수 있어야 한다.
7. 유명 코치의 콘텐츠가 일반 코치의 수업으로 연결되어야 한다.
8. 테니스 전용 기능과 스포츠 공통 기능을 기술적으로 분리한다.
9. 관리자의 편의보다 실제 코트에서의 코치 사용성을 우선한다.
10. 기능 수보다 학습 순환의 완결성을 우선한다.
