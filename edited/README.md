# edited — 사람 편집본과 그 분석

파이프라인 입력이 아니다. **사람이 같은 원본으로 무엇을 만들었는지** 확인하는 기준이다.

| 파일 | 무엇 |
|---|---|
| `lecture_forehand.webm` | 사람 편집본 8:03 (원본 `raw/c01_01~07` 12:41 → 압축 63%) |
| `lecture_forehand.transcript.json` | 그 편집본의 whisper 전사 |
| `lecture_forehand.analysis.json` | **씬 12개 단위 분해** — 자막·그래픽·SFX·줌·트랜지션·BGM·밀도까지 |

|---|---|---|---|

무발화 3개는 각각 대응하는 포인트가 정해져 있다. 임의 배치하면 안 된다.

## 편집본에만 있고 원본에 없는 것

1. **후녹음 훅 내레이션** (0:00–0:13.5) — 원본 어디에도 없는 발화
2. **챕터 카드 3장** — 검은 화면 + 흰 텍스트, 각 2~3초
3. **드릴 장면** (4:12.5–4:36) — 매트 위 런지. **의상이 다르다**(줄무늬 카라티/녹색 반바지) = 다른 날 촬영
4. **타이틀 자막** — 번호 리스트, 질문("거리잡기를 어려워하는 이유?"), 강조
5. **BGM 전 구간**, SFX(pop/beep/ding/화염)
6. **그래픽** — 오른발 축에 원, 골반에 회전 화살표, 겨드랑이에 원, 농구공 오브젝트 합성

## 편집 문법에서 읽어낸 규칙

- **줌으로 컷을 감춘다** (`zoom_grammar.used_to_conceal_cuts: true`)
- 줌 평균 간격 65초, 강조용만. 리듬 줌 없음
- SFX는 독립 이벤트가 아니라 **자막 등장에 동기화**된다
- 무발화 소재를 두 가지로 쓴다: **짧은 시범**(6.5초) / **긴 몽타주**(78초 + 상단 고정 체크리스트 + 구간별 하이라이트 이동)
- 챕터 카드 진입은 `black_card`, 카드에서 본편은 `hard_cut`
- 첫 포인트(①시선)에 112초 = 전체의 23%를 쓴다
