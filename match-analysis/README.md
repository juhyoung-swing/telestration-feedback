# 경기 영상 분석

경기 영상 하나에서 타격·스윙 종류·공 궤적·낙구 지점을 뽑아 선수별 리포트로 만든다.

## 검증된 것

`match_b.mp4` 45~112초 · 랠리 6개 · 타격 44개 · **학습 없이 공개 가중치 + 후처리만**

| 항목 | 방법 | 결과 |
|---|---|---|
| 코트 좌표계 | 키포인트 14점 수동 보정 → 호모그래피 | 재투영 오차 **3.3 cm** |
| 타격 카운트 | 공-선수 최근접 | 17타 랠리에서 **17타** |
| 선수 귀속 | 공에 더 가까운 쪽 | P1 23 / P2 21 (교대 규칙 강제 없음) |
| 스윙 종류 | 타격 시점 손목과 몸 중심 비교 | 44/44 판정 |
| 낙구 지점 | 공의 3D 포물선 복원 (중력으로 방정식) | 좌우 교대 규칙 14/21 |
| 선수 검출 | YOLOv8x | P1 100% / P2 96% |
| 공 검출 | YOLOv5l6u + TTA + 칼만 | **71%** |

**소리를 쓰지 않는다.** 스코어보드 없는 영상, 직접 촬영한 영상에 그대로 적용된다.

## 안 되는 것

**공 검출 71%가 유일한 병목이다.** 낙구 정확도·표본 수·타격 누락이 전부 여기서 파생된다.

```
타격 순간에 공이 라켓·몸에 가려진다     건너편 선수(P2)는 그 순간 52%까지 떨어짐
낙구 추적 48~52%                   타격 44번 중 22번만 낙구를 알아냄
낙구 정확도                        전수 검증 결과 절반 정도만 확실
스트로크 속도                      공중의 공을 지면에 투영해 계산 → 구조적 과대평가
```

인/아웃 판정 · 서브 성공률 · 스트로크 속도는 **넣지 않았다.** 신뢰 수준에 못 미친다.

## 촬영 조건 — 카메라 높이가 성패를 가른다

| | 코트가 화면에서 차지하는 세로 비중 | 재투영 오차 | 판정 |
|---|---|---|---|
| 실내 · 높은 카메라 | 70% | 5.1 cm | 최적 |
| 실외 · 높은 카메라 | 54% | 6.7 cm | 충분 |
| 실외 · **낮은 카메라** | 13% | **92.8 cm** | **불가** |

> 코트가 화면 세로의 50% 이상을 차지하도록, 베이스라인 뒤 높은 위치에서 촬영할 것.
> 비트레이트 20 Mbps 이상. H.264는 비트가 모자라면 빠른 작은 물체부터 뭉갠다.

**낮은 화각에서는 이 기능이 통째로 죽는다.** 랠리 검출은 살지만(호모그래피를 안 쓰므로)
분석은 코트 좌표계에 얹혀 있어서 못 쓴다.
