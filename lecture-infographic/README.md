# 인포그래픽 생성

강의 대본과 **실제 프레임**에서 학습용 도해 이미지 프롬프트를 뽑는다.
영상은 흘러가고 학습자는 코트에서 8분짜리를 다시 볼 수 없다. 정지된 한 장이 필요하다.

이 기능은 **프롬프트까지** 만든다. 이미지는 외부 생성 툴을 거친다.

## 나온 것 — 도해 4장

```
① 시선    노란 화살표가 시선의 길           c01_02  60.0s
② 골반    노란 실선/점선이 회전의 순서       c01_03  44.0s
③ 피니시   노란 원이 비어 있어야 할 자리      c01_04  80.0s
④ 골반 드릴 노란 화살표가 다리 없이 도는 골반  편집본 261.0s
```

전부 **보이지 않는 것**이다. 자세는 사진으로도 보인다. 사진이 못 보여주는 걸 노랑이 그린다.

## 절차 8단계

```
① 유닛 경계 잡기        자동    s2 지시서가 이미 씬으로 나눠 놓았다
② 구간 대사 전부 읽기    자동    문제/원인/해법/왜 로 묶으면 축이 드러난다
③ 화면에 있는 것 세기    자동    s2 에 그래픽·줌·자막이 시각까지 기록돼 있다
④ 축 한 문장 뽑기       반자동   대본 원문에 있는지 문자열로 검증할 수 있다
⑤ 참조 프레임 고르기     ← 병목
⑥ 노랑 하나 정하기      반자동
⑦ 영문 프롬프트         자동    THE FIGURE 는 고정, 나머지는 템플릿
⑧ 확인 목록            자동
```

**⑤가 유일한 병목이다.** 컨택트시트 자동 생성까지는 되고, 고르는 건 사람 눈이 든다.
`find_loop` 의 움직임 버스트/유지 판정을 재사용해 후보를 뽑을 수 있다.

## 색 규칙 — 고정

```
navy    #17335F   올바른 동작, 모든 선
yellow  #E4EF3D   봐야 할 것 딱 하나
grey    #98A0B2   잘못된 동작 (수업 후 대조에만)
red     #E2483D   X 표시 전용
```

**노랑이 둘 이상이면 어디를 볼지 모른다.** 줄일 수 없으면 그림이 두 장이어야 한다는 신호다.

## 시리즈로 만들 때 — THE FIGURE

참조 프레임은 **자세만** 준다. 옷·머리까지 가져오면 촬영일이 다른 도해끼리 다른 사람이 된다.
`THE FIGURE` 블록이 옷·머리·신발·선 굵기를 토씨까지 고정한다.
없으면 대머리가 나오고, 코치가 그날 입은 줄무늬 폴로가 그대로 그려진다.

## 방법 자체가 스킬로 정리돼 있다

```
src/lesson-diagram-prompt/
  SKILL.md                      절차 8단계 + 원칙
  references/prompt-blocks.md    영문 프롬프트 블록별 작성법 + 통 템플릿
  references/what-failed.md      해보고 안 된 것 9가지
  examples/                      완성된 4장 + 참조 프레임
```

**`what-failed.md` 를 먼저 읽는다.** 탑뷰가 왜 전부 이상했는지(참조를 붙일 수 없는 뷰라서),
텍스트만 쓰면 왜 교과서 자세가 나오는지(묘사가 길수록 평균에 수렴하므로) 등이 있다.
