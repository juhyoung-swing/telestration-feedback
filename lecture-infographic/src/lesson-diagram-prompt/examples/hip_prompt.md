# 2. 이 유닛의 전체 내용

편집본 `02:45.0 – 04:12.5` · 1분 28초.

### 문제
```
회원분들이 볼 때 골반을 사용하지 못하기 때문에 파워가 제일 안 실려요.
```

### 원인
```
그 이유는 오른발을 잘 보시면 — 오른발의 축이 뒤로 가 있게 되면 자꾸 뒤로 무너집니다.
오른발을 고정시키고 뒤로 빠지게 되면 당기게 되니까 파워를 낼 수가 없어요.
```

### 해법  ★ 이 유닛의 축
```
스탠스를 왼발을 잡아서 누르고, 제일 중요한 건 여기서 오른발을 먼저 사용해 줌으로써
골반 회전을 만드는 거예요.
여기서 골반 회전이 만들어져야 라켓이 뒤따라 나오면서 채찍처럼 파워를 딱 내게 되는데.
제일 중요한 거는 내가 오른발에 회전을 함으로써 라켓보다 먼저 골반을 회전해 주는 거.
이 회전하는 순간이 가장 파워를 낼 수 있는 중요한 순간입니다.
```

### 한 가지 더
```
골반을 사용한다고 해서 오른발을 여기서 딱 버티는 게 아니라 자연스럽게 끌려나가는 거.
발을 버티면 안 되고 오히려 그냥 가듯이 끌려나가야 돼요.
```

### 정리 — 화면에 자막으로 박힘
```

04:06.0  2. 몸이 먼저 따라감

```


그래픽이 셋이라 **공간은 이미 전달된다.** 안 되는 것은 **순서**다 — `라켓보다 먼저 골반을`.

# 3. 한 장으로 옮기면

담을 것은 이 하나다.

```
라켓보다 먼저 골반을 회전해 주는 거.
```

## 구성

순서는 시간이라 한 장에 안 들어간다. 그런데 **이미 간 것**과 **아직 안 간 것**을 한 화면에
같이 두면 순서가 드러난다. 지나간 길은 실선, 올 길은 점선이다.

정면에서 본 한 사람. 골반은 이미 돌았고 라켓은 아직 뒤에 있는 순간.

```
오른발    돌아가 있다 — 뒤꿈치가 들리고 발끝이 앞을 향한다
골반      카메라 쪽으로 열려 있다
회전 화살표  골반을 감고 도는 굵은 실선 화살표      ← 노랑 · 이미 간 것
라켓      아직 몸 뒤에 남아 있다
지연 화살표  라켓이 나중에 지날 길, 가는 점선 호     ← 노랑 · 아직 안 간 것
```

**실선은 이미, 점선은 아직.** 그 둘이 한 화면에 있으면 `골반이 먼저, 라켓이 나중`이 읽힌다.
채찍이 그렇다 — 손잡이가 먼저 가고 끝이 늦게 따라온다.

## 받았을 때 확인

- **라켓이 몸 뒤에 남아 있는가.** 앞으로 나와 있으면 이 도해의 뜻이 사라진다
- 골반과 가슴이 정면을 향해 열려 있는가
- 오른발 뒤꿈치가 들리고 발끝이 앞을 향하는가
- 실선 화살표가 골반에, 점선 호가 라켓에 붙어 있는가. 뒤바뀌면 순서가 거꾸로 읽힌다
- 두 화살표의 선 스타일이 눈에 띄게 다른가
- 노랑이 두 화살표뿐인가 · 얼굴·글자가 없는가

## 안 나오면 줄일 순서

```
반드시   열린 골반 · 뒤에 남은 라켓 · 실선 화살표(골반)
있으면   점선 호(라켓)
없어도   오른발 디테일 · 베이스라인
```
