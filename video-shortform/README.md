# 숏폼 추출

레슨 영상 하나에서 쓸 만한 구간을 골라 **세로 클립 여러 개**로 뽑는다.
Reels · Shorts · TikTok 규격.

## `../video-edit` 와 다른 점

| | video-edit | 여기 |
|---|---|---|
| 입력 | 강의 원본 + **대본** | 레슨 원본, **대본 없음** |
| 판단 기준 | 대본과 일치하는가 | **좋은 구간인가** |
| 출력 | 완성 강의 1개 (가로) | 세로 클립 여러 개 |
| 무음 | 무음 ≠ 삭제 (시범 보호) | 무음이 거의 없음 (계속 말함) |

**판단이 "일치" 가 아니라 "선별" 이라 코드를 공유하지 않는다.**

## 데모만이라고 하는 이유

**`.py` 파일이 0개다.** 전부 명령을 손으로 돌려서 만들었다.
옮길 코드가 없고 산출물과 편집 지시서만 있다.

## 두 가지가 특이하다

**CapCut 자동자막을 썼다.** 데스크톱 프로젝트의 `draft_info.json` 이 평문이라
439줄 자막을 읽어 `transcript_raw.srt` 로 뽑았다. `output/draft_backup_0812/` 참고.

**테니스 용어 오인식을 손으로 교정했다.**

```
락캠 / 락캠면        → 라켓 / 라켓면
세미에스턴 / 위스턴   → 세미웨스턴 / 웨스턴
압수하듯이          → 악수하듯이
수행 / 수행하세요    → 스윙 / 스윙하세요
탓점               → 타점
```

**전사 후처리에 테니스 용어 사전이 필요하다는 증거다.** 다른 기능에도 해당한다.

## 세로 크롭이 약하다

```
현재   1080×1920 · 중앙 고정 크롭 (x=656)
```

**공이나 사람을 따라가지 않는다.** 경쟁 제품은 카메라맨처럼 공을 따라가는 리프레임을 판다.
`../lecture-summary` 의 `clip_loop()` 이 `subject_track.json` 으로 인물을 따라가니
그걸 가져오면 된다.
