# run 001 — 폐기. 입력을 잘못 넣었다

**입력으로 쓴 `lecture_forehand.webm` 은 무편집 원본이 아니라 사람이 편집한 편집본이었다.**

기획서 §5 와 스키마 `meta.source.file` 이 이 파일을 원본으로 지목했는데, 실제로는
`c01_01~07` 7개 클립(무편집, 12:41)을 편집해 만든 결과물(8:03, 압축률 64%)이다.

확인 근거:
- 편집본 14.0초 = c01_01 의 0.0초 ("안녕하세요. 김준코치입니다")
- 편집본 앞 14초는 원본 어디에도 없는 발화 → 후녹음 훅
  "이번 영상에서는 선수처럼 강력한 포핸드를 만들기 위해 꿀팁 3가지를…"
- 필러 제거 확인: 원본 "첫째는 시선 거리 잡기, **그 다음에** 두 번째는" → 편집본 "첫째는 시선 거리잡기, 두 번째는"

## 그래서 무엇이 무효인가

| 산출물 | 상태 |
|---|---|
| `output/visual_events.json` | 무효 — Gemini 가 편집본을 분석했다 |
| `output/crosscheck.md` | 무효 — 위 결과를 검증한 것 |
| `output/audio_16k.wav` | 편집본의 오디오 |
| 전사 | `edited/lecture_forehand.transcript.json` 으로 이동 (편집본 참조 자료로는 유효) |

## 그런데 이 실패가 설명해주는 것

Gemini 의 `exclusions` 4개가 전부 오판이었고(잘라내라는 135초 중 118초가 발화),
`reason` 이 모두 `equipment` 였으며 note 에 "카메라 앵글 이동", "카메라 위치 변경"이
반복됐다. **편집본이라서 이미 컷과 앵글 전환이 있었고, Gemini 는 그 편집 컷을
장비 조작으로 오해했다.**

`silent_demo` 로 잡은 5:55–6:28 도 발화가 94% 였다. 편집본은 이미 무음이 제거돼
있어서 무음 시범이 남아 있지 않았다.

즉 **무편집 원본이 아니면 s1 시각 패스는 애초에 성립하지 않는다.**
