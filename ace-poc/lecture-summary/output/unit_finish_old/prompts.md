# UNIT 4 · 피니시 공간 — 넣을 그림 생성 프롬프트

영상에서 프레임을 떠낼 수 있는 건 다 떴다. 여기 넷은 **정지 프레임으로는 못 만드는 것**이다.
왜 못 만드는지가 각 프롬프트 안에 들어 있다 — 그게 빠지면 생성기가 사진 같은 걸 만들어 온다.

---

## 공통 — 모든 프롬프트 앞에 붙일 것

```
테니스 포핸드 온라인 강의 페이지에 넣을 설명용 일러스트를 만든다.
학습자는 초·중급 성인이고, 코트에서 휴대폰으로 이 페이지를 본다.

이 유닛의 주제는 "피니시 공간"이다.
코치의 핵심 지도는 이것 하나다 — 겨드랑이와 팔이 붙으면 당기는 스윙이 되니,
가슴과 팔 사이에 농구공 하나만큼의 공간을 만들어 라켓 헤드를 던지듯 마무리하라.

스타일
- 깔끔한 선화(line illustration). 사진 아님, 3D 렌더 아님
- 배경 흰색 또는 투명. 코트 배경 그리지 말 것
- 인물은 얼굴 없는 단순 실루엣 또는 선화. 특정 인물처럼 보이면 안 됨
- 강조색은 딱 두 가지만: 네이비 #17335F(기본 선), 옐로우 #E4EF3D(강조)
  잘못된 동작을 표시할 때만 회색 #98A0B2
- 그림 안에 글자를 넣지 말 것. 설명은 페이지가 캡션으로 붙인다
- 가로 16:9
```


### 방향은 화면 기준으로만 쓴다

생성기는 테니스를 모른다. "면이 앞을 향한다", "위쪽으로 열린다" 는 테니스 아는
사람끼리 통하는 말이고, 생성기에는 아무 뜻이 없다. 실제로 그렇게 썼더니
라켓 세 개가 전부 같은 각도로 나왔다.

그래서 방향은 전부 화면 기준으로 쓴다.
```
시점  오른손잡이 선수를 왼쪽 옆에서 본 측면도
네트  화면 오른쪽에 있다. 공은 화면 오른쪽으로 날아간다
앞    = 화면 오른쪽        뒤 = 화면 왼쪽
위    = 화면 위            아래 = 화면 아래
```

## 1. 스윙 궤적  ★ 가장 필요함

**왜 필요한가**
영상은 정면 고정 카메라다. 라켓이 지나간 자리는 프레임에 안 남는다.
"아래에서 위로 사선"이라는 말은 코치가 계속 하는데, 학습자는 그 경로를 볼 방법이 없다.
정지 컷을 몇 장 이어 붙여도 궤적은 안 보인다. 이건 그려야만 존재한다.

**어떻게 그리는 그림인가 — 이걸 먼저 못 박는다**
다중노출(스트로보) 그림이다. 같은 사람을 세 번 그린다.
세 인물이 각각 라켓을 쥐고 있고, 세 라켓 헤드를 지나는 선이 궤적이다.
인물 한 명에 라켓 세 개를 띄우는 그림이 아니다.

**무엇을 묘사하나**
```
오른손잡이 테니스 선수의 포핸드 스윙을, 같은 사람을 세 번 겹쳐 그린
다중노출(multiple exposure / stroboscopic) 일러스트.
왼쪽 옆에서 본 측면도. 네트는 화면 오른쪽에 있다.

■ 같은 인물을 세 번 그린다. 셋 다 라켓을 손에 쥐고 있다.
  라켓이 공중에 따로 떠 있으면 안 된다. 반드시 손과 이어져 있어야 한다.

  ① 화면 왼쪽 · 무릎 높이
     몸이 화면 왼쪽으로 틀어져 있고, 라켓을 잡은 팔이 아래로 내려가 있다.
     라켓 면이 지면을 향해 엎어져 있다 — 납작한 타원으로 보인다.

  ② 화면 가운데 · 허리 높이 · 공을 맞히는 순간
     몸이 화면 오른쪽을 향해 열리기 시작한다. 팔이 몸 앞으로 나와 있다.
     라켓 면이 화면 오른쪽(네트)을 정면으로 향한다.
     옆에서 보고 있으므로 면은 두께만 보인다 — 타원이 아니라 가는 세로 막대.
     여기가 타원으로 그려지면 그림 전체가 틀린 것이 된다.

  ③ 화면 오른쪽 · 어깨보다 높은 곳 · 마무리
     몸이 화면 오른쪽을 완전히 향하고, 팔이 위로 올라가 있다.
     라켓 면이 화면 왼쪽 위(하늘)를 향해 젖혀져 있다 — 60도 기울어진 타원.

  세 인물은 조금씩 겹쳐도 된다. ①과 ③은 흐리게(불투명도 35%),
  ②만 진하게 그린다.

■ 궤적선
  세 라켓의 헤드를 지나는 하나의 매끄러운 곡선.
  ①의 헤드에서 시작해 ②를 거쳐 ③의 헤드에서 끝난다. 끝에 화살촉 하나.
  옐로우, 굵은 선. 인물보다 앞 레이어에 그린다.
  아래로 살짝 처졌다가 오른쪽 위로 뻗는 사선. 완만한 U자가 아니다.

■ 지면선 한 줄, 화면 아래쪽에 가로로. 세 인물의 발이 이 선에 닿는다.

■ 색: 인물과 라켓은 네이비 선화, 궤적선만 옐로우. 얼굴은 그리지 않는다.
```

**받았을 때 확인할 것**
- 인물이 **세 명**인가. 한 명이면 다시 만든다
- 라켓 셋이 전부 **손에 쥐어져** 있는가. 하나라도 떠 있으면 다시
- ② 지점의 라켓이 **가는 막대**인가. 타원이면 다시
- 궤적선이 세 라켓 **헤드**를 지나는가. 손잡이나 허공을 지나면 틀린 것

## 2. 피니시 공간 측면 도해

**왜 필요한가**
영상이 정면이라 가슴과 팔 사이의 **깊이**가 안 보인다.
정면에서 보면 팔이 붙어 있는지 떨어져 있는지 구분이 안 된다.
측면으로 돌려야 그 공간이 보인다. 그런데 측면 촬영분이 없다.

**무엇을 묘사하나**
```
오른손잡이 선수의 피니시 순간 상체. 왼쪽 옆에서 본 측면도. 네트는 화면 오른쪽.

- 가슴과 위팔 사이에 뚜렷한 빈 공간이 있다
- 그 공간에 농구공 크기의 원을 그려 넣는다. 원이 공간에 딱 맞게 들어간다
- 원은 옐로우 채움 40% 투명도, 테두리 실선
- 상체·팔·라켓은 네이비 선화
- 원의 지름이 어깨너비의 대략 절반쯤 되게 — 실제 농구공 비율

핵심은 "공이 들어갈 자리가 있다"는 것 하나다. 다른 요소를 넣어 흐리지 말 것
```

## 3. 잘못 vs 올바름 대조

**왜 필요한가**
영상에 잘못된 예시가 따로 안 찍혀 있다. 코치가 말로만 설명한다.
"겨드랑이 붙은 스윙"이 어떤 모양인지 학습자가 상상해야 하는 상태다.
둘을 나란히 놓으면 한 번에 이해된다.

**무엇을 묘사하나**
```
같은 인물의 피니시 자세 두 개를 좌우로 나란히 놓는다. 같은 각도, 같은 크기.

왼쪽 — 잘못된 피니시
- 위팔이 몸통에 붙어 있다. 겨드랑이에 공간이 없다
- 라켓이 몸 쪽(화면 왼쪽)으로 당겨져 가슴 높이에서 멈춰 있다
- 전체를 회색으로 그린다

오른쪽 — 올바른 피니시
- 가슴과 팔 사이에 공간이 있다 (농구공 하나 크기)
- 라켓이 화면 위쪽, 어깨보다 높은 곳까지 올라가 있다
- 네이비 선화, 그 공간만 옐로우로 강조

두 그림 사이에 얇은 세로 구분선.
글자 없이 색만으로 옳고 그름이 읽혀야 한다
```

## 4. 3단계 순서 도식

**왜 필요한가**
코치는 세 동작을 순서대로 시키는데 영상에서는 흘러가버린다.
연습할 때 순서를 확인할 한 장이 필요하다.

**무엇을 묘사하나**
```
왼쪽에서 오른쪽으로 세 컷을 나란히 놓고 화살표로 잇는다.

① 골반 임팩트 — 골반이 돌아가며 임팩트를 맞는 순간. 골반 부위를 옐로우로
② 팔꿈치 밀기 — 왼손바닥이 오른 팔꿈치를 밀어 올린다. 미는 손과 방향 화살표를 옐로우로
③ 마무리 — 라켓이 화면 위쪽, 어깨보다 높은 곳에서 끝난다. 가슴–팔 사이 공간을 옐로우로

- 각 컷은 상체 위주 네이비 선화
- 컷 사이 화살표는 얇은 네이비
- 번호는 그리지 말 것. 페이지가 붙인다
```

## 검수 기준

받아본 그림이 아래를 만족하는지 본다.

- 옐로우가 **한 곳만** 강조하는가. 여러 군데면 초점이 없어진다
- 코치 얼굴이나 특정인 닮은 얼굴이 없는가
- 그림 안에 글자가 없는가 (한글이 깨져 나오는 경우가 많다)
- 배경에 코트·펜스·관중이 없는가 — 동작만 남아야 한다
- 1번은 **면의 각도 변화 세 개**가 보이는가. 궤적선만 있으면 반쯤만 된 것
