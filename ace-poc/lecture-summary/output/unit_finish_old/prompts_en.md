# 이 수업에서 더 만들 만한 것

다른 유닛까지 보면 만들 값어치가 있는 게 셋 더 있다.

## A. 시선 — 위에서 본 타점 거리  ★ 이 강의 최대 공백

`s04`(시선)는 2분 가까이 쓰는데 그래픽이 화살표 하나뿐이다. 그런데 코치의 주장이 전부 거리다.

```
"타점 자체를 옆에 두고 거리를 멀리 두게 되는데"
"정면에다 두면 옆이 정면이 되게 되죠"
"거리를 정확하게 멀리 두게 돼요"
```

거리는 **위에서 봐야만** 보인다. 정면 카메라로는 앞뒤가, 측면으로는 좌우가 안 보인다.
그리고 위에서 찍은 영상이 없다 — 그리지 않으면 존재하지 않는 그림이다.

```
탑뷰 두 컷. 코트를 위에서 내려다본 도해.
왼쪽  시선이 정면 → 첫 스텝이 정면으로 빠짐 → 공이 몸 가까이 → 타점 원이 몸에 붙음 (회색 + 빨간 X)
오른쪽 시선이 옆 → 유닛턴 → 공이 옆에 → 타점 원이 몸에서 멀리 (네이비 + 노랑)
두 컷의 몸-타점 거리를 노란 치수선으로 표시. 오른쪽이 눈에 띄게 길다
```

## B. 골반 — 오른발 축의 위치

`s07`은 원과 화살표가 있어 공간은 전달되는데, **축이 앞이냐 뒤냐**가 발 위에서만 보인다.

```
발자국 탑뷰 두 컷.
왼쪽  오른발 축이 뒤 → 체중이 뒤로 → 몸이 무너지는 화살표 (회색 + 빨간 X)
오른쪽 오른발이 돌면서 축이 앞 → 골반 회전 화살표 (네이비 + 노랑)
```

## C. 전체 한 장 요약 — 3×3

코치가 이미 3×3으로 말했고 편집자가 6개를 자막으로 박아놨는데 영상 안에 흩어져 있다.
한 장으로 모으면 그게 곧 커리큘럼 목차이자 코트에서 보는 복습 카드다.

```
시선    ① 유닛턴          ② 공 째려보기      ③ 임팩트 끝까지 바라보기
골반    ① 오른발 돌리며 회전  ② 몸이 먼저 따라감   ③ 라켓을 채찍치듯이
피니시  ① ?               ② ?              ③ ?
```

**피니시 행이 비어 있다.** 다른 둘은 `02:23.5` `04:02.5`에 3단계 자막이 박혀 있는데
`s10`에는 없다. 코치에게 물어 채우거나, 이 유닛에서 뽑아 정해야 한다.
