# 수강생용 요약 — 수업 전 / 수업 후

편집본이 이미 이 구조로 되어 있다. 코치가 앞에서 한 번, 뒤에서 한 번 세 가지를 말하는데
**말이 다르다.**

```
s02  00:13.5–00:41.5  목차   1. 시선(거리잡기)      2. 골반 회전 사용하는 법   3. 피니쉬 자세
s11  05:57.5–06:44.5  요약   1. 유닛턴하고 시선보기   2. 골반사용(오른발회전)    3. 공간만들어주며 피니쉬
```

앞은 **이름표**, 뒤는 **동작 지시**다. 앞은 "뭘 배우는지"를 알려주고 뒤는 "뭘 하라"고 시킨다.
수업 전 자료와 수업 후 자료의 차이가 정확히 이것이다.

---

## 원칙 하나 — 잘못된 예시는 수업 후에만

수업 전 자료에 오답을 넣으면 안 된다.
학생은 아직 자기 폼을 모른다. 목표도 모르는데 오답부터 보면 둘이 섞인다.

수업 후에는 반대다. 한 번 해봤으니 **자기 폼과 대조할 기준**이 필요하고,
그때 비로소 "이건 하지 마세요"가 뜻을 갖는다.

```
수업 전   목표만 보여준다.        올바른 자세, 노랑 강조
수업 후   대조를 보여준다.        잘못(회색+빨간 X)  ↔  올바름(네이비+노랑)
```

# 수업 전 — 3분 예습

목표: 8분을 헛보지 않게. 뭘 보러 가는지만 알면 된다. 읽는 데 1분.

## 1. 오늘 한 줄

```
포핸드에 파워와 정확도가 안 실리는 이유는 세 가지다 — 시선, 골반, 피니시.
```

출처 · `s02` `00:31.0` "이 세 가지가 완벽하게 돼야 파워도 실릴 수 있고 그다음에 정확도도 올라가고"

## 2. 오늘 배울 세 가지

`s02` 의 자막 세 개를 그대로 쓴다. 편집자가 이미 골라놓은 문구다.

| | | 편집본 |
|---|---|---|
| 1 | 시선 (거리잡기) | `00:21.0` |
| 2 | 골반 회전 사용하는 법 | `00:24.0` |
| 3 | 피니쉬 자세 | `00:27.5` |

각 줄 옆에 **목표 자세 한 장**. 잘못된 예시는 넣지 않는다.

```
1  유닛턴하고 옆을 보는 자세     c01_02  60.0s
2  오른발을 축으로 도는 자세     c01_03  (미확정)
3  라켓이 어깨 위로 올라간 자세   c01_04  54.0s
```

## 3. 완성형 스윙 · 8초 루프

글보다 빠르다. "이걸 만들러 온다"를 한 번에 보여준다.
몽타주에서 스윙 한 사이클만 잘라낸 무음 루프. 자동 탐지 결과 `07:40.4–07:43.3`.

## 4. 볼 때 이것만 신경 쓰세요

```
코치가 "첫째" "두 번째" "세 번째" 라고 말하는 세 지점에서
화면 위쪽에 초록 자막이 뜬다. 그 세 개만 기억하면 된다.
```

편집본 `02:23.5` `04:02.5` `06:02.5` 에 각각 3단계 자막이 뜬다.

# 수업 후 — 코트에서 꺼내 보는 것

목표: 자기 폼과 대조. 8분을 다시 볼 수는 없으니 30초에 훑는다.

## 1. 오늘 한 것 · 3×3 체크리스트

`s11` 요약 자막(대분류)과 각 유닛의 3단계 자막(세부)을 합친다.
**이게 이 강의의 전부다.** 아홉 줄.

| | ① | ② | ③ |
|---|---|---|---|
| **시선** | 유닛턴 | 공 째려보기 | 임팩트 끝까지 바라보기 |
| **골반** | 오른발 돌리며 회전 | 몸이 먼저 따라감 | 라켓을 채찍치듯이 |
| **피니시** | ? | ? | ? |

출처 · 시선 `02:23.5` `02:26.5` `02:29.0` · 골반 `04:02.5` `04:06.0` `04:09.0`

> **피니시 행이 비어 있다.** 다른 둘은 자막이 박혀 있는데 `s10` 에는 없다.
> 코치가 정해줘야 이 표가 완성된다. 이 강의의 유일한 구조적 구멍.

## 2. 흔한 실수 셋 — 여기서 처음 등장

각 유닛의 잘못된 자세를 회색 + 빨간 X 로. 오른쪽에 올바른 자세를 나란히.

| | 잘못 | 올바름 | 코치의 말 |
|---|---|---|---|
| 시선 | 정면으로 보고 감 `c01_02 10.0s` | 유닛턴하고 옆을 봄 `c01_02 60.0s` | "멀어서 실수하는 것보다 가까워서 실수하는 경우가 많거든요" |
| 골반 | 오른발 축이 뒤 (미확정) | 오른발 돌며 축이 앞 (미확정) | "발을 버티면 안 되고 오히려 그냥 가듯이 끌려나가야 돼요" |
| 피니시 | 겨드랑이 붙음 `c01_04 25.5s` | 농구공 공간 `c01_04 54.0s` | "농구공 크기만큼만 라켓이 감싸주면 피니시가 예쁜 스윙이 만들어집니다" |

## 3. 동작별 루프 · 3개

몽타주가 이미 세 구간으로 나뉘어 있다. 빨간 원이 구간을 표시해놨다.

| | 편집본 | 길이 |
|---|---|---|
| 유닛턴 | `06:47 – 07:09` | 22초 |
| 골반 | `07:09 – 07:30` | 21초 |
| 피니시 공간 | `07:30 – 08:03` | 33초 |

각 구간에서 스윙 한 사이클만 잘라 8초 안팎의 무음 루프로. 코트에서 폰으로 보는 물건.

## 4. 집에서 할 것

코치가 **연습량을 말한 유일한 자리**다.

```
골반 드릴 — 하루 20회 × 3세트
편집본 04:12.5–04:36.0
"이 동작을 집에서 하루에 20회씩 3세트만 반복해 주신다면 자연스럽게 골반이 돌아갈 거예요"
```

시선과 피니시에는 연습량이 없다. 코치에게 물어 채우거나, 없는 채로 두고
"피니시는 농구공을 겨드랑이에 끼고 확인" 정도의 확인법만 준다.

## 5. 마지막 한마디

`s11` 끝의 코치 당부. 세 가지에 안 들어가지만 코치가 따로 강조한 것.

```
"저희 회원들을 보면 공을 진짜 끝까지 안 봐요.
 임팩트 후까지 좀 더 보고 따라간다는 느낌을 받아주시면 좋을 것 같습니다."
```

# 만들어야 하는 것

| | 수업 전 | 수업 후 |
|---|---|---|
| 텍스트 조판 | 한 줄 · 세 가지 목록 | 3×3 체크리스트 |
| 프레임 컷 | 목표 자세 3장 | 잘못/올바름 6장 |
| 그려야 할 그림 | **없음** | 시선 탑뷰 2컷 · 골반 발자국 2컷 · 피니시 3장 |
| 루프 | 완성형 1개 | 동작별 3개 |

**수업 전 자료에는 새로 그릴 그림이 없다.** 프레임을 떠서 쓰면 된다.
그림이 필요한 건 전부 대조를 보여주는 수업 후 자료다.

## 막힌 것

1. **피니시 3단계** — 3×3 표가 이것 때문에 미완성
2. **골반 축 대조 프레임** — 하체 줌 구간에서 다시 찾거나 추가 촬영
3. **시선·피니시 연습량** — 코치 확인 필요
