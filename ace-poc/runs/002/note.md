## 이번에 드러난 것

**1. 사람 편집본의 composition 수치를 원본에 그대로 쓰면 안 된다.**
`composition.json` 의 `horizontal_pct`·`headroom_pct` 는 크롭된 편집 화면 기준이다.
그걸로 '하체 오른발' 위치를 계산했더니 그래픽이 허공에 떴다.
→ `subject_track.py` 를 만들어 원본에서 인물 박스를 직접 찾는다.
카메라가 고정이라 중앙값 배경 + 차분으로 모델 없이 된다 (검출률 1426/1521 프레임).

**2. 무발화 클립에 자막을 달면 환각이 화면에 박힌다.**
`c01_05/06/07` 은 발화가 없는데 whisper 가 용어집을 메아리처럼 뱉는다.
몽타주에 "스탠스, 피니시, 골반 회전, 스탠스, 타점" 이 자막으로 떴다.
→ 지시서의 `speech: false` 를 s6 이 읽어 그 클립은 자막을 만들지 않는다.

**3. 줌에 길이가 없으면 렌더러가 규칙을 지어낸다.**
지시서 `zoom[]` 에 `at` 만 있고 길이가 없어서 "블록 끝까지" 로 때웠더니
conceal_cut 줌은 0.04초, 강조 줌은 59초가 됐다.
→ `duration_sec` 를 지시서에 명시. 판단은 지시서가, 실행만 렌더러가.

**4. 줌이 걸린 구간에서는 몸에 붙는 그래픽 좌표를 다시 계산해야 한다.**
글자는 화면 좌표라 그냥 얹으면 되지만, 도형은 크롭된 프레임 기준으로 옮겨야 한다.
안 옮기면 발을 가리키던 원이 종아리를 가리킨다. 6개 중 4개가 해당됐다.

**5. ffmpeg 재설치는 답이 아니었다.**
설치된 9.0.1 빌드에 libass/freetype 이 없다. 같은 formula 를 다시 깔아도 같다.
→ 자막·그래픽을 Pillow 로 PNG 에 그리고 `overlay` 필터 하나로 얹는다.
프레임마다 그리면 14,460장이라 '구성이 바뀌는 순간'으로 구간을 쪼개 216장만 그린다.
