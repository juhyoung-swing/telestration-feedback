# 숏폼 데모 — 레슨 영상 1개 → 숏폼 클립 3~5개

> **데모다. 제품 기능이 아니다.**
> 보여줄 메시지: "레슨 영상 하나 던지면 편집된 숏폼이 캡컷에 떠 있다."
> 산출물은 실제로 재생되는 세로 영상 3~5개. 리포트가 아니라 **영상이 결과물**이다.

## 0. 입력

- `input/lecture_raw.mp4`
  - 11분 45초, 1920x1080, 60fps, h264 + aac
  - **실제 1:1 테니스 레슨 현장 녹화.** 클레이 코트, 야외. 코치 1 + 수강생 1
  - 바구니 피딩 드릴, 코트에 공 수십 개, 카메라는 코트 옆 사람 눈높이 고정
  - 마스크 착용 상태로 대화 → 전사 오인식 예상
  - **무음 구간이 거의 없음** (11분 45초 중 무음 3구간, 전부 640~645초 구간에 몰림). 즉 계속 말하고 있어서 무음 기반 컷이 안 통한다. **의미 단위로 끊어야 하고 그건 LLM이 한다.**
- 대본 없음. **필요 없음.** 숏폼은 원본에서 좋은 구간을 고르는 작업이라 정답지가 불필요하다.

## 1. Gate 0 — 경로 결정 (제일 먼저, 10분)

사용자가 캡컷 데스크톱(macOS)을 설치하고 영상을 넣어 **자동자막을 생성한 뒤 저장**한다. 그다음 확인:

```bash
ls ~/Movies/CapCut/User\ Data/Projects/com.lveditor.draft/
# 프로젝트 폴더 안에 draft_info.json 이 있는지
# 평문 JSON으로 열리는지 (head -c 200 으로 확인)
```

| 결과 | 경로 |
|---|---|
| 평문 JSON으로 열림 | **경로 B (자동)** |
| 암호화/바이너리 | **경로 A (반자동)** |

**이 확인 전에 capcut-cli를 설치하거나 코드를 짜지 말 것.** 경로가 갈린다.

## 2. 경로 A — 반자동 (안전, 항상 가능)

1. 캡컷에서 자막을 SRT로 내보내기 (사용자 조작)
2. LLM이 SRT를 읽고 `output/edit_sheet.md` 생성 (§4 형식)
3. 사용자가 캡컷에서 그대로 자르고 자막 교체 → 내보내기
4. 완성 클립을 `output/clips/` 에 수집

## 3. 경로 B — 자동 (데모 임팩트 큼)

### 도구
```bash
npm install -g capcut-cli@latest   # 반드시 최신
capcut --version                    # 0.18.0 이상인지 확인. 미만이면 중단
```

⚠️ **보안 주의 (반드시 준수)**
- 0.17.2 이하: `capcut fixture` 번들에 device_id·MAC·하드디스크 ID가 남는 알려진 문제. 이 버전 쓰지 말 것.
- 0.17.0 이하: 드래프트 폴더명을 통한 명령 실행, 자막 색상을 통한 ffmpeg 필터 인젝션 경로 존재.
- **외부에서 받은 드래프트 파일을 절대 열지 말 것.** 우리가 만든 것만 다룬다.
- 공개 이슈에 번들 첨부하지 말 것.

⚠️ **macOS 제약**
- 파일명이 `draft_content.json`(Windows)이 아니라 **`draft_info.json`**. capcut-cli 문서는 Windows 기준이므로 경로/파일명 옵션을 macOS에 맞게 지정해야 할 수 있음.
- **macOS에서는 자동 내보내기(export)가 안 될 가능성이 높다.** 문제 없음 — 드래프트 생성까지가 목표고, 내보내기는 사용자가 캡컷에서 직접 한다.
- 원본 드래프트는 **작업 전 반드시 백업**한다.

### 순서
1. 캡컷 프로젝트에서 자막 추출 (capcut-cli 또는 SRT 내보내기)
2. LLM이 컷 구간 + 다듬은 자막 결정
3. capcut-cli로 숏폼 드래프트 생성 (클립당 1개 또는 1개 프로젝트에 순차 배치)
4. 사용자가 캡컷에서 열어 확인 → 내보내기

**capcut-cli가 특정 기능(예: 단어별 색상 강조)을 지원하지 않으면 억지로 우회하지 말 것.** 그 항목만 `edit_sheet.md`에 "수동 작업" 으로 표기하고 넘어간다. 클립당 30초면 손으로 된다.

## 4. LLM이 결정할 것

### 4-1. 클립 선정
- **3~5개.** 각 20~40초.
- **클립 하나 = 교습 포인트 하나.** "백스윙 크게 하지 마세요" 같은 팁 1개가 숏폼 1개.
- 선정 기준: 그 구간만 떼어놔도 말이 되는가 / 즉시 써먹을 수 있는 팁인가 / 시범 동작이 함께 나오는가
- 문장 중간에서 끊지 말 것. 앞뒤 0.3초 여유.

### 4-2. 자막 다듬기 (핵심 — 자동자막을 그대로 쓰지 않는다)

**a. 구어체 정리**
```
자동자막: 어 그러니까 이제 백스윙을 너무 크게 하시면 준비가 늦어지거든요 그래서
다듬은 것: 백스윙이 크면 / 준비가 늦어집니다
```
"어", "그", "이제", "그래서", "거든요" 같은 군더더기 제거. 의미는 절대 바꾸지 말 것.

**b. 줄바꿈은 의미 단위로**
- **한 줄 12~15자, 최대 2줄.** 자동자막은 시간으로 끊어서 어색하게 갈라진다.
- 나쁨: `백스윙이 크면 준비가 / 늦어집니다`
- 좋음: `백스윙이 크면 / 준비가 늦어집니다`

**c. 강조 단어** — 클립당 2~3개만 지정. `edit_sheet.md`에 표기.

**d. 훅 자막** — 첫 1.5초, 본문과 별개 레이어, 큰 글씨. 15자 이내. 낚시 금지, 내용과 일치할 것.

**e. 위치** — 세로 영상 하단 UI를 피해 화면 하단에서 약 20% 위로.

### 4-3. 테니스 용어 교정
자동자막이 반드시 틀리는 것들. 전사 결과에서 아래 유형을 찾아 고친다.
- 스플릿스텝, 발리, 발리어, 크로스, 다운더라인, 포핸드, 백스윙, 팔로스루, 타점, 스탠스, 톱스핀, 슬라이스, 라켓면, 그립
- 확신 없는 교정은 하지 말고 `edit_sheet.md`에 `?` 표기해서 사용자 확인을 받는다.

### 4-4. 세로 크롭 (고정값, 추적 없음)
1080p 소스에서 9:16 크롭 창은 **608 x 1080**. 클립마다 셋 중 하나를 고른다.

| 프리셋 | x 오프셋 | 쓸 때 |
|---|---|---|
| 좌 | 0 | 인물이 화면 왼쪽 |
| 중앙 | 656 | 인물이 가운데 |
| 우 | 1312 | 인물이 화면 오른쪽 |

- 판단은 해당 구간의 프레임을 실제로 뽑아보고 정한다 (`ffmpeg -ss ... -frames:v 1`).
- 한 클립 안에서 인물이 크게 이동하면 그 클립은 선정에서 제외하거나, 구간을 더 짧게 자른다.
- 출력 1080x1920, 30fps.

## 5. 산출물

```
output/
  edit_sheet.md        ★ 편집 지시서 (경로 A/B 공통)
  clips/               완성 세로 영상 3~5개
  subtitles/           클립별 다듬은 자막 (srt)
  transcript_raw.srt   원본 자동자막 (비교용)
  frames/              크롭 판단에 쓴 프레임
```

### edit_sheet.md 형식
클립마다:

| 항목 | 내용 |
|---|---|
| 구간 | 02:14.2 ~ 02:41.0 (26.8초) |
| 훅 | 백스윙이 크면 늦습니다 |
| 크롭 | 우 (x=1312) |
| 강조 | "늦어집니다", "타점" |
| 수동 작업 | 단어별 색상은 캡컷에서 |
| 자막 | (다듬은 전문, 줄바꿈 포함) |
| 원본 자막 | (비교용) |

맨 위에 교정한 용어 목록과 `?` 표기 항목을 모아둘 것.

## 6. 하지 말 것

- 사람 추적 크롭 (YOLO 등) — 고정값으로 간다
- Opus Clip 등 외부 자동 선별 서비스 — 한국어 약하고 야외 레슨엔 안 맞음
- BGM, 트랜지션, 이펙트 — 내용이 보이게
- 클립 6개 이상
- 낚시성 훅
- capcut-cli 우회 해킹 — 안 되는 건 수동으로 표기

## 7. 순서

1. **Gate 0** — 사용자에게 캡컷 설치·자동자막 생성 요청 → `draft_info.json` 확인 → 경로 결정
2. 자막 추출 → `transcript_raw.srt`
3. **자막 검수** — 전사 전문을 사용자에게 보여주고 테니스 용어 오인식 확인받기 (이 단계 건너뛰지 말 것)
4. 클립 선정 + 자막 다듬기 → `edit_sheet.md` → **사용자 승인 대기**
5. 프레임 뽑아 크롭 결정
6. 경로 A: 사용자가 캡컷 작업 / 경로 B: 드래프트 생성 → 사용자가 열어 확인
7. 완성 클립 수집

각 단계 끝나면 짧게 보고하고 진행할 것. 특히 4번은 승인 없이 넘어가지 말 것.
