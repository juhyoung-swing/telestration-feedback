# 포핸드 핵심 세 가지 — 인포그래픽 에셋 목록

8분짜리 영상 하나를 수업으로 돌린다고 할 때 필요한 그림 전부.
**영상이 못 하는 것만** 넣었다. 영상이 이미 보여주는 건 프레임을 떠서 쓰면 되고 그리지 않는다.

색 규칙은 전부 공통이다.

```
navy   #17335F   올바른 동작, 모든 선
yellow #E4EF3D   봐야 할 곳 하나
grey   #98A0B2   잘못된 동작 — 인물 전체가 회색
red    #E2483D   X 표시 전용
```

# 수업 전 — 뭘 배우는지 알고 들어가게

## A1. 오늘의 세 가지 · 3×3 카드

| | |
|---|---|
| 언제 | 수업 시작 전, 강의 페이지 맨 위 |
| 왜 | 코치가 이미 3×3으로 말했고 편집자가 6개를 자막으로 박아놨는데 **8분 안에 흩어져 있다.** 한 장으로 모으면 그게 목차이자 나중에 복습 카드가 된다 |
| 형식 | 표 한 장. 그림 아님. 텍스트 조판 |
| 프레임 | 필요 없음 |

```
시선    ① 유닛턴          ② 공 째려보기       ③ 임팩트 끝까지 바라보기
골반    ① 오른발 돌리며 회전  ② 몸이 먼저 따라감    ③ 라켓을 채찍치듯이
피니시  ①  ?              ②  ?               ③  ?
```

> **피니시 행이 비어 있다.** 시선은 `02:23.5`, 골반은 `04:02.5`에 3단계 자막이 박혀 있는데
> `s10`에는 없다. 코치에게 물어 채워야 한다. 이 강의의 유일한 구조적 구멍이다.

# 수업 중 — 유닛마다 한 장씩

## B1. 시선 — 위에서 본 타점 거리  ★ 이 강의 최대 공백

| | |
|---|---|
| 언제 | 시선 유닛 안 |
| 왜 | `s04`는 2분 가까이 쓰는데 그래픽이 화살표 하나뿐이다. 그런데 주장이 전부 **거리**다. 거리는 **위에서 봐야만** 보인다 — 정면 카메라로는 앞뒤가, 측면으로는 좌우가 안 보인다. **탑뷰 영상은 없다. 그리지 않으면 존재하지 않는 그림이다** |
| 근거 | `"타점 자체를 옆에 두고 거리를 멀리 두게 되는데"` / `"거리를 정확하게 멀리 두게 돼요"` / `"멀어서 실수하는 것보다 가까워서 실수하는 경우가 많거든요"` |
| 프레임 | `c01_02 10.0s` 정면으로 보는 자세 · `c01_02 60.0s` 유닛턴하고 옆을 보는 자세 |
| 형식 | **탑뷰 도해 2컷.** 사진 참조는 자세 확인용이고 그림 자체는 위에서 내려다본 도해 |

```
왼쪽   시선이 정면 → 첫 스텝이 정면으로 빠짐 → 공이 몸 가까이
       타점 원이 몸에 붙어 있다.  회색 + 빨간 X
오른쪽  시선이 옆(유닛턴) → 공이 옆에 → 타점을 멀리 둔다
       타점 원이 몸에서 떨어져 있다.  네이비 + 노랑

두 컷의 몸–타점 거리를 노란 치수선으로 표시. 오른쪽이 눈에 띄게 길다.
```

## B2. 골반 — 오른발 축의 위치

| | |
|---|---|
| 언제 | 골반 유닛 안 |
| 왜 | `s07`은 원·화살표가 있어 회전 방향은 전달되는데, **축이 앞이냐 뒤냐**는 발 위에서만 보인다. 영상은 측면/대각이라 발의 앞뒤 위치가 안 읽힌다 |
| 근거 | `"오른발의 축이 뒤로 가 있게 되면 자꾸 뒤로 무너집니다"` / `"오른발을 먼저 사용해 줌으로써 골반 회전을 만드는 거예요"` |
| 프레임 | **미확정.** `c01_03 28~40s` 구간에 스탠스가 있으나 축의 앞뒤 대조가 선명한 컷을 아직 못 찾았다. 하체 줌 구간(`편집본 03:03.0`)에서 다시 찾아야 한다 |
| 형식 | **발자국 탑뷰 2컷** |

```
왼쪽   오른발 축이 뒤 → 체중이 뒤로 → 몸이 무너지는 화살표.  회색 + 빨간 X
오른쪽  오른발이 돌면서 축이 앞 → 골반 회전 화살표.        네이비 + 노랑
```

## B3~B5. 피니시 — 3장  *(만듦 · `docs/unit_finish/prompts_en.md`)*

| | 참조 프레임 | 무엇 | 색 |
|---|---|---|---|
| B3 | `c01_04 25.5s` | 위팔이 몸통에 밀착 — 당기는 피니시 | 회색 + 빨간 X |
| B4 | `c01_04 70.0s` | 농구공이 가슴–팔 사이에 끼어 있음 | 네이비 + 노랑 원 |
| B5 | `c01_04 54.0s` | 라켓이 어깨 위, 몸이 열린 완성형 | 네이비 + 노랑 공간 |

> 왜 3장인가 — 소품(농구공)은 **확인 도구지 목적이 아니다.** B5에서 공을 빼고 공간만
> 노랗게 남겨야 "공 없이도 이 자리를 유지하라"가 전달된다.

# 정리

| | 에셋 | 상태 |
|---|---|---|
| 전 | A1 3×3 카드 | 피니시 행 미정 — **코치 확인 필요** |
| 전 | A2 완성형 루프 | 피니시용은 만듦. 유닛턴·골반용 추가 |
| 중 | B1 시선 탑뷰 | **참조 프레임 확보** · 프롬프트 미작성 |
| 중 | B2 골반 발자국 | **참조 프레임 미확정** |
| 중 | B3~B5 피니시 3장 | **프롬프트 완성** |
| 후 | C1 체크리스트 | A1 확정되면 바로 |
| 후 | C2 홈 드릴 | 편집본에서 떠내야 함 |

**새로 그려야 하는 그림은 7장**이다 (B1 2컷 · B2 2컷 · B3~B5 3장).
나머지는 프레임을 떠서 쓰거나 텍스트 조판이다.

1. **피니시 3단계** — 코치가 정해줘야 A1·C1이 완성된다
2. **골반 축 대조 프레임** — 하체 줌 구간에서 다시 찾거나, 없으면 추가 촬영
