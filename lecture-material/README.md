# 수강생 학습자료

완성된 강의에서 **수업 전 / 수업 후** 두 장을 만든다.
코트에서 8분짜리를 다시 볼 수는 없으니 30초에 훑는 물건이 필요하다.

## 나온 것

```
before.html   수업 전   미리보기 루프 · 소개 · 개요 · 배울 내용 3유닛 (도해 + 설명)
after.html    수업 후   오늘 한 것 · 확인할 것 3유닛 (대조 + 루프 + 체크) · 집에서 할 것
포핸드_수강생자료.html   두 장을 합쳐 이미지·영상 전부 인라인한 단일 파일 (5.0MB)
```

## 두 장이 뒤집히는 방식

```
수업 전                          수업 후
────────────────────────────────────────────────────
소개  …세 가지를 익힙니다          오늘 한 것  …세 가지 팁입니다 + 3줄 목록
개요  절차 · 목적
배울 내용                        확인할 것
  ① 시선 · 거리 잡기               ① 유닛턴으로 몸을 틀고 공을 끝까지 본다
  [도해] 목표 자세                 [잘못 ↔ 올바름] 각각 동작 → 결과
  설명 문단                        [루프] · 코트에서 확인 ☐☐☐ · 놓치기 쉬운 것
                                 집에서 할 것 — 골반 드릴 (도해)
                                 마지막으로
```

같은 틀(`.unit`)을 쓰고 **안의 내용만 뒤집는다.**

```
도해(목표)  →  대조(판정)
설명 문단   →  체크리스트
이름표      →  동작 지시     s02 목차 자막 → s11 요약 자막
```

## 지켜야 하는 규칙

```
수업 전에 오답을 넣지 않는다
  학습자는 아직 자기 폼을 모른다. 목표도 모르는데 오답부터 보면 둘이 섞인다.

앞뒤 제목이 달라야 한다
  같으면 두 장이 같은 페이지로 읽힌다. 원본이 앞뒤로 다르게 말해주면 그대로 쓴다.

빈 슬롯은 섹션째 뺀다
  "확인 항목이 아직 정해지지 않았습니다" 같은 제작 메모를 학습자에게 보이지 않는다.

대본에 없으면 지어내지 않는다
  코치 인용을 그대로 넣지도 않는다 — 요약 페이지에 말이 그대로 들어가면 요약이 아니다.
```

## 자동 / 사람이 정하는 것

```
자동     루프 탐지(find_loop) · 인물 추적 크롭 · 프레임 뜨기 · HTML 렌더 · 번들
사람     유닛 경계 · 각 유닛의 축 문장 · bad/good 정지컷의 초 · 카피
```

텍스트는 전부 `src/student_pages.py` 맨 위 상수 4개(`LESSON` `UNITS` `FRAME` `LOOPS`)에 있다.
**의도한 구조다** — 판단은 상수에, 렌더러는 렌더만.

## 조건부인 것

**체크리스트는 원본에 3단계 자막이 있어야 나온다.** 시선·골반은 있었고 피니시는 없었다.
없으면 지어내지 않고 한 줄만 둔다. 코치 확인이 필요한 자리다.

**연습량도 코치가 말한 자리만 쓴다.** 골반만 "하루 20회 × 3세트" 가 있어서
섹션 제목을 `집에서 할 것 — 골반 드릴` 로 좁혔다.

## 알려진 버그

`src/student_pages.py` 의 `shot()` 이 크롭을 고정으로 박고 있다.

```python
crop=820:940:620:60      # 이 카메라 프레이밍 전용
```

바로 아래 `clip_loop()` 은 `subject_track.json` 의 인물 박스로 알아서 맞추는데
`shot()` 만 안 그렇다. **다른 앵글 영상이 오면 정지컷에서 사람이 잘린다.**

## 실행

```bash
python src/student_pages.py     # before.html · after.html · 에셋
python src/bundle_page.py       # 단일 파일로 묶기
```
